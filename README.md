# YForex

## 🪩 Airport – Club Simulator

Ein Idle-/Tycoon-Spiel im Ordner [`airport-club/`](airport-club/): Baue den Club **„Airport“**
vom kleinen Laden zum Kult-Club aus — Terminal 1 (Mainfloor), Terminal 2 (VIP-Etage) freischalten,
Personal einstellen, DROPs auslösen, Promis begrüßen und irgendwann neu eröffnen.

**Starten:**

```bash
cd airport-club
python3 -m http.server 8080
# dann http://localhost:8080 im Browser öffnen (am besten am Handy / im mobilen Format)
```

Der Spielstand wird automatisch im Browser gespeichert (inkl. Offline-Einnahmen).
Das Spiel ist PWA-ready und kann später z. B. mit Capacitor als App-Store-App verpackt werden.
